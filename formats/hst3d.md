# 3D High Speed (HST) toolpaths — Mastercam 2017

## Layers
```
UI       mcmsurf.dll  msurf_hmm_* commands (ui_commands.tsv), HST*ParamPage dialogs (ui_fields_mcmsurf.tsv)
toolpath mckernel.dll TPHSTToolPath / TPOptRoughToolPath / TPHybridWSToolPath / TP2DHSTCoreAreaMill / TPZCut ...
           -> internal job classes (e.g. OptRoughToolPath) build *macro programs* and run them
engine   mchmm.dll    "Mastercam HMM" 9.6.41 (CNC Software): own entity database, macro language
                      (lexer + AST: if/for/do, functions, variables), "plans", .emm model files, tbb threading
2D core  mcce.dll     the Dynamic Mill engine (formats/dynamic.md) — reused by OptiRough per Z level
```
Data exchange uses temp files in the job folder: `.emm` (mchmm models: stock `tmphmmstk.emm`, passes), `.stl`
boundaries (`HSTBNDRY.STL`), `tmp*.tmp`; HST formulas can come from XML (`<HST_Formula_Data>`).

## OptiRough = Z-profile slicing + the 2D Dynamic engine per level
`TPOptRoughToolPath::Compute` -> job `OptRoughToolPath` (vtable 0x180155f00) whose overrides build:
1. Machining Passes macro with "Get Optimized Roughing Z Profile Passes" (slice the model into Z-level regions),
2. a 2D Stock Model macro (bounding box + waterline passes),
3. per region, `OptRoughDynPockExecutioner` (chain FUN_180107864 -> FUN_18010687c -> FUN_180106624 -> FUN_180108510)
   calls **`mcce::MCCECalcDynPock`** — the same engine as 2D Dynamic Mill,
4. a Toolpath Linking Passes macro (imported passes + linking plan).
`FUN_180108f1c` fills `CDynPockParm` from the OptiRough settings with the same field meanings as 2D:
R = D/2 (+0x28), corner radius (+0x30), engagement = acos(1 - s/R) with s = OptiRough stepover (+0x38, capped 170 deg),
min radius (+0x40), micro lift (+0x48), approach 0.65 D when "from outside" (+0x50), plunge angle (+0x68), pitch (+0x70),
Z clearance (+0x88), helix radius (+0x90), loop radius (+0x98), slot width (+0xa0), gap (+0xe0), tolerance (+0x110,
+0x58 = 20x), same flag groups (0x100..0x1000, 0x10000..0x80000, 0x2000, 0x40000000, 8 metric).
So the in-plane engagement model validated on 2D Dynamic Mill files (formats/dynamic.md) also governs OptiRough.
