# Documentation index (formats/) - 2026-10-16

Start with `../README.md` (getting started, licence) and `../NOTES.md` (current state, build, regressions, oracle).
Rule behind every spec: no improvisation - each statement cites decompiled code / original data, else it says
**NOT DECODED**. Status: **complete** = the area is specified and matches the code; **partial** = specified with
listed NOT DECODED gaps or unported parts; **stale** = known to disagree with the code in places (named); **log** = a
dated record (read the newest entries first).
