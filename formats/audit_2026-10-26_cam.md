# Deviation audit 2026-10-26: CAM engines and posting

Read-only review of the main tree `<repo>` as it is now (with another agent's uncommitted
edits), plus `~/mastercam-re/work/wt_ncidrill/viewer/bnci_update.c` and `drill_section` in `wt_ncidrill/viewer/nci_write.c`.
Checked against the "no improvisation" rule and `formats/user_decisions.md` (decision ids cited as there: B6-x, B7-x, B8-x, B9-x,
3D-x, Q1..Q34, D1..D4, M1..M4, S-D1, P-D1/2, SIM1..3, N1..N3, R-1, UI-1). The class names follow `formats/improvisation_review.md`
(DECODED / CORRELATED / SUBSTITUTE / STUB / IMPROVISED). Line numbers are main tree unless the path says `wt_ncidrill`.

Method: I grepped every file in scope for "ours", "inferred", "stand-in", "[ND]", "NOT DECODED", "measured", "approx", "heuristic",
"fallback", "instead", "getenv", unit-blind literals (`0.001`, `0.05`, `0.1`, `x D` factors) and fallback defaults, then read the
code around each hit. I also sampled the main generators (gen_contour, gen_pocket, gen_dynamic*, gen_area_hmm, every gen_* in cam3d_*),
nc_post_part, nci_write and cam_fileop params_from_record. This pass does not re-check the DECODED citations line by line.
